# Materiais editoriais para Instagram

Legendas, referências e prompts de carrosséis sobre programação, agentes de IA e engenharia reversa.

Cada pasta corresponde a uma versão editorial. Abra `legenda.txt`, `fontes.txt`, `LEIA-ME.txt` e os arquivos JSON em um editor de texto. Não há aplicação para instalar ou servidor para iniciar.

Esta edição pública contém somente os materiais editoriais. As 42 imagens dos carrosséis utilizam fotografias pessoais e não foram incluídas, assim como os arquivos ZIP que as duplicavam. Referências às imagens nos prompts e instruções descrevem o processo original; substitua-as por fotografias ou ilustrações que você tenha autorização para usar. Os arquivos locais originais foram preservados.
